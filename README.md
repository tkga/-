# สมุดบัญชีคนขับ

แอปจดรายรับ-รายจ่ายสำหรับคนขับแกร็ป ใช้บนมือถือ ไม่ต้องสมัครบัญชี ไม่ต้องมีเซิร์ฟเวอร์
**ข้อมูลเก็บในเบราว์เซอร์ของเครื่องคุณเท่านั้น** ไม่ถูกส่งไปที่ไหน

## จุดเด่น: แยก "ช่องทาง" ของเงิน

ทุกรายการเลือกช่องทางได้ ตัวเลขจึงไม่ปนกัน

| ช่องทาง | ใช้กับ | นับเป็น |
|---|---|---|
| แกร็ป | รายรับ/รายจ่าย | กำไรแกร็ป (หักค่าเสื่อมและค่าประจำให้ด้วย) |
| เกม | รายรับ/รายจ่าย | กำไรเกม (รายรับ − ต้นทุน) |
| อื่นๆ | รายรับ | รายได้อื่น |
| ส่วนตัว | รายจ่าย | หักตอนท้าย ไม่ปนกับต้นทุนแกร็ป |

- เป้าหมายรายวันเลือกได้ว่าจะนับ **แกร็ปอย่างเดียว** (ค่าเริ่มต้น) หรือ **ทุกช่องทาง**
- สถิติอย่าง กำไรต่อกิโลเมตร/ชั่วโมง และ ต้นทุนต่อรายรับ คิดจากแกร็ปล้วน
- หน้าสรุปรายเดือนมีการ์ด "รายได้ทุกช่องทาง" และตารางรายวันสลับดูได้ทั้งแบบแกร็ป/ทุกช่องทาง

## ข้อมูลการวิ่ง (เที่ยว / ชั่วโมง / กิโลเมตร)

ไม่ต้องกรอกแยกต่างหาก ระบบรวมให้จากรายการแกร็ปของวันนั้น

- ตอนจดรายรับช่องทาง **แกร็ป** หมวด รับผู้โดยสาร / ส่งอาหาร / ส่งพัสดุ จะมีช่อง **กิโลเมตร** และ **เวลาที่ใช้ (นาที)** (ไม่บังคับ)
- บันทึก 1 รายการ = **1 เที่ยว** (ทิป โบนัส เกม และรายได้อื่น ไม่นับเป็นเที่ยว)
- การ์ด "ข้อมูลการวิ่ง" ของวันแก้ตรงๆ ไม่ได้ ต้องแก้หรือลบที่รายการ ตัวเลขจะปรับตามเอง
- ค่าเสื่อมรถ, กำไรต่อชั่วโมง/กม./เที่ยว คำนวณจากตัวเลขรวมนี้

## วิธีคำนวณ

```
กำไรแกร็ป = รายรับแกร็ป − รายจ่ายแกร็ป − (กม. × ค่าเสื่อมต่อ กม.) − ค่าใช้จ่ายประจำรายวัน
```

- ค่าใช้จ่ายประจำ (ผ่อนรถ ประกัน โทรศัพท์ ฯลฯ) หารเป็นรายวัน หักทุกวันตั้งแต่ **วันแรกที่มีข้อมูล** ถึงวันนี้ แม้วันนั้นไม่ได้ขับ
- รายเดือนหารด้วยจำนวนวันของเดือนนั้น รายปีหารด้วย 365/366
- ค่าประจำเลือกได้ว่าเป็นของ "แกร็ป" หรือ "ส่วนตัว" (เช่น ค่าเน็ตบ้านไม่ควรหักจากกำไรแกร็ป)
- เพิ่ม/ลบค่าประจำมีผลย้อนหลังกับทุกวัน

## อัปขึ้น GitHub แล้วใช้งานบนมือถือ

1. สร้าง repository ใหม่บน GitHub (ชื่ออะไรก็ได้ เช่น `driver-ledger`)
2. กด **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ใส่ (รวมโฟลเดอร์ `icons`) กด **Commit changes**
3. ไปที่ **Settings → Pages** เลือก **Deploy from a branch** → Branch `main` / โฟลเดอร์ `/ (root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
5. เปิดลิงก์บนมือถือ แล้วเพิ่มลงหน้าจอหลัก
   - Android (Chrome): เมนู ⋮ → **ติดตั้งแอป** / **เพิ่มลงในหน้าจอหลัก**
   - iPhone (Safari): ปุ่มแชร์ → **เพิ่มลงในหน้าจอโฮม**

แก้ไฟล์แล้ว commit ใหม่ ลิงก์เดิมจะอัปเดตเอง (เปิดแอปตอนมีเน็ตหนึ่งครั้ง) หลังเปิดครั้งแรกแอปใช้งานออฟไลน์ได้

## สำรองข้อมูล (สำคัญ)

เพราะข้อมูลอยู่ในเครื่อง ถ้าล้างข้อมูลเบราว์เซอร์ ถอนแอป หรือเปลี่ยนเครื่อง ข้อมูลจะหาย
ไปที่ **ตั้งค่า → ดาวน์โหลดไฟล์สำรอง** เป็นระยะ (แอปจะเตือนเมื่อเกิน 7 วัน) และใช้ **นำเข้าจากไฟล์สำรอง** ที่เครื่องใหม่

> ไฟล์สำรอง `.json` มีข้อมูลการเงินของคุณ **อย่าอัปโหลดขึ้น repository สาธารณะ**
> ตัวโค้ดใน repo ไม่มีข้อมูลส่วนตัวของใคร ข้อมูลจริงอยู่แค่ในเครื่องคุณ

## โครงสร้างไฟล์

```
index.html            หน้าเว็บ
style.css             ธีมมืด
logic.js              ตรรกะคำนวณล้วนๆ (ไม่แตะหน้าจอ ทดสอบด้วย Node ได้)
app.js                หน้าจอ 3 แท็บ และการโต้ตอบ
sw.js                 ให้เปิดแอปได้แม้ไม่มีเน็ต
manifest.webmanifest  ข้อมูลสำหรับติดตั้งเป็นแอป
icons/                ไอคอนแอป
tests/                เทสต์ตัวเลข (ตัวอย่างข้อมูลตรงกับสกรีนช็อตแอปเดิม)
```

ทดลองรันบนเครื่อง: `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000`
รันเทสต์: `node --test tests/logic.test.js` (ต้องมี Node 18 ขึ้นไป)

## หมายเหตุ

- ฟอนต์ (IBM Plex Sans Thai, Pixelify Sans) โหลดจาก Google Fonts ครั้งแรกที่มีเน็ต ถ้าโหลดไม่ได้จะใช้ฟอนต์ของเครื่องแทน
- วันที่ใช้เวลาของเครื่อง ถ้าแอปเปิดค้างข้ามเที่ยงคืน "วันนี้" จะเปลี่ยนให้เอง รายการหลังเที่ยงคืนจะถูกจดเป็นของวันใหม่ ย้อนไปจดวันเก่าได้ด้วยปุ่ม ‹
